# 🧼 批量图片背景去除工具

一个纯前端的本地工具，帮助你在浏览器中选择电脑上的文件夹，调用多家 AI / 图像处理服务批量去除图片背景并统一生成白色背景的成品图。所有 API Key 等配置均保存在本地浏览器的 `localStorage` 中，下次打开即可继续使用。

## ✨ 主要特性

- 🚀 **批量处理**：选择本地文件夹后，自动扫描其中的图片（支持 PNG/JPG/WebP），可递归包含子目录。
- 🧠 **多模型接入**：内置 Remove.bg、通义千问 Image-Edit、PhotoRoom API、OpenAI 图像编辑（GPT）以及 Google Gemini Image Edit 的调用模板。
- 🎛️ **灵活配置**：支持自定义并发数、输出格式（PNG/JPG）、文件命名策略（同级后缀或按服务商建子目录）。
- 💾 **数据本地持久化**：API Key、模型参数、基础设置以及最近的处理记录都存储在浏览器本地，不会上传任何信息。
- 👀 **实时反馈**：展示详细的任务日志、文件处理状态与缩略图预览，方便排查异常。
- 📎 **一键日志复制**：快速复制执行日志，便于反馈和排错。

## 📦 环境需求

- 建议使用最新版本的 Chromium 浏览器（Chrome / Edge / Arc 等）。需支持 [File System Access API](https://developer.mozilla.org/docs/Web/API/File_System_Access_API)。
- 由于跨域限制，大多数第三方 API 不允许直接在浏览器前端调用。如果遇到 CORS 问题，请在本地搭建代理或通过企业网关转发请求。

## 🚀 启动方式

```bash
# 克隆或下载仓库后进入项目目录
npm install  # 可选，无必需依赖

# 启动本地静态服务器
npm run dev
# 或者
python3 -m http.server 8000
```

然后在浏览器访问 `http://localhost:8000`，即可看到应用界面。

> ⚠️ 直接双击 `index.html` 打开虽然可以预览界面，但部分 API 由于浏览器安全策略会被限制，建议始终通过本地服务器访问。

## 🛠️ 配置步骤

1. 在「API 服务配置」区域启用想要使用的服务，并填写对应的 API Key / 模型等参数。
2. 点击右上角的「保存 API 配置」按钮，或等待自动保存。
3. 选择源文件夹和输出文件夹：
   - 首次操作浏览器会弹出权限申请，请允许读取或写入。
   - 如果勾选「包含子文件夹」，会递归处理所有子目录中的图片。
4. 根据需要调整并发数、输出格式等参数。
5. 点击「开始处理」启动任务。

所有配置会持久化在浏览器本地，下次打开页面即会自动恢复。若需重置，使用「重置配置」按钮即可。

## 🔌 各服务调用说明

| 服务 | 说明 | 常见注意事项 |
| ---- | ---- | ------------ |
| **Remove.bg** | 官方背景去除接口，直接返回透明或指定颜色背景。 | 浏览器直连时需留意 CORS 限制；免费额度有限。 |
| **通义千问 Image-Edit** | DashScope 图像编辑接口，通过 prompt 去除背景。 | 需要启用兼容模式 API；支持度依赖模型版本。 |
| **PhotoRoom API** | 适用于电商产品图分割，可设置输出背景色。 | 需在开发者平台启用 SDK Key。 |
| **OpenAI 图像编辑 (GPT)** | 使用 `responses` 接口生成白底版本。 | 账号需开通新的图像能力，调用成本较高。 |
| **Google Gemini Image Edit** | 使用 `imageinpainting` 等模型生成白底图片。 | 需在 Google AI Studio 创建 API Key。 |

> 📌 **温馨提示**：多数官方接口并未直接开放浏览器调用，可能需要搭建后端代理。应用内置的调用逻辑主要方便本地调试或连接自建网关，实际生产环境请根据服务条款进行落地。

## 📁 输出文件策略

- **原名 + 提供商后缀**：在输出目录直接生成，例如 `shoe.png` → `shoe_removeBg.png`。
- **按提供商创建子文件夹**：自动在输出目录创建如 `removeBg/`、`photoroom/` 等子目录，文件名保持原始名称。

PNG 输出保留透明通道，JPG 输出会在保存前填充纯白底色。

## 🧠 数据持久化

- API 配置与全局设置存储在 `localStorage`，键值分别为：
  - `backgroundRemoverConfig`
  - `backgroundRemoverHistory`
- 任务运行产生的缩略图仅在当前会话中保留，刷新页面后会释放内存。
- 历史记录最多保留最近 200 条处理信息，方便统计使用情况。

## 🐞 常见问题排查

1. **提示浏览器不支持文件系统访问**：换用最新版 Chrome / Edge，并确保通过 `https://` 或 `http://localhost` 访问。
2. **接口返回 401/403**：检查 API Key 是否正确、是否有调用权限或额度。
3. **CORS 错误**：多数服务禁止前端直连，建议通过自建服务器做请求转发。
4. **输出文件未生成**：确认浏览器授予了“读写”权限，可尝试重新选择输出目录。
5. **JPG 转换失败**：部分移动端浏览器不支持 `canvas.toBlob`，建议使用桌面浏览器或保持 PNG 输出。
